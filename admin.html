How to Update Hadiths

Option 1: Google Sheets (Recommended)

  1. Create a Google Sheet with two columns: text and source
  2. Add your hadiths (one per row)
  3. Go to File → Share → Publish to web
  4. Select "Comma-separated values (.csv)" and publish
  5. Copy the CSV link and paste it below

Option 2: Admin Panel (This Page)

Use the editor below to add, edit, or remove hadiths. Changes are saved to your browser's localStorage.
